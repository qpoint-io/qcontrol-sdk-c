
  =============================================
   qcontrol SDK for C - Demo Environment
  =============================================

  Build a plugin:

    cd examples/file-logger
    make build                    # builds .so (shared library)
    make dist                     # builds .o  (object file for packaging)

  Build all example plugins:

    cd examples
    make build

  Build plugins by type:

    make build-file              # file plugin shared libraries
    make build-exec              # exec plugin shared libraries
    make build-net               # net plugin shared libraries

  Run a command with qcontrol instrumentation (list a built plugin under a
  behavior's `plugins` in config.yaml; its `path` must be absolute):

    qcontrol run --config <config.yaml> --behavior <behavior> -- <command>

  Example - instrument 'cat' with a built plugin (README.md shows how to
  generate the plugins.yaml it uses):

    cd examples
    qcontrol run --config ./plugins.yaml --behavior file-logger -- cat /etc/hostname

  Useful commands:

    qcontrol --help               # full CLI help
    qcontrol run --help           # instrumentation options
